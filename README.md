Twin Scenes is a spot-the-difference game: two near-identical pictures sit side by side and ten small, fair differences hide between them. Three hand-painted scenes (a harbor at sunset, a cottage garden, a lantern night market), a 3-minute clock, combos for quick finds, hints that ring a hiding difference, a 2x loupe, and synthesized sound — all drawn procedurally in the browser, no images and no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and hunt. Click a difference to mark it on both pictures, press H for a hint, L for the loupe, P to pause, R to restart, M to mute. The four screenshots in screenshots/ are real renders of the game itself.
